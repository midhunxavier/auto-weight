# Evidence and sources

The [copying regression case](../examples/copy-repair/README.md) preserves the frozen issue, proposals and trial reports. Its base and donor were trained in an earlier copying study with the same model configuration and initialization seed. The original training recipe, checkpoint index and results are in the [specificity study archive](https://github.com/midhunxavier/weight-space-programming/blob/9b4a7b1f2a0156caba723158b4c3ff31c1ede2bd/packages/weight-edit-toolkit/research/inspector/examples/specificity-validation-20261105/README.md).

The [inspector archive](https://github.com/midhunxavier/weight-space-programming/blob/9b4a7b1f2a0156caba723158b4c3ff31c1ede2bd/packages/weight-edit-toolkit/research/inspector/README.md) preserves the previous diagnostic methods, original public replays, prospective studies and failed experiments. Those studies examine head identification. The repair case evaluates output behavior before and after an edit.

The [JSON repair case](../examples/json-repair/README.md) uses the public [SmolLM2-135M-Instruct checkpoint](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct) and locally generated fine-tuning and evaluation examples. The case preserves the upstream revision, training recipe, frozen issue, proposals and evaluation reports.

AutoWeight originated in [Weight Space Programming PR #3](https://github.com/midhunxavier/weight-space-programming/pull/3). Recorded run artifacts preserve the paths and hashes from the machine where each experiment ran. The example instructions recreate the inputs in a new checkout.
